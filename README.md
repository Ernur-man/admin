# Admin Panel

A modern admin panel built with **React**, **TypeScript**, and **Vite**. Designed for managing applications efficiently with a clean, professional interface.

## 🎯 Features

- ✨ Modern, responsive design
- ⚡ Fast performance with Vite build tool
- 🛡️ TypeScript for type safety
- 🧭 React Router for navigation
- 📡 Axios for API integration
- 🎨 Less styling support

## 🛠️ Tech Stack

- **Frontend**: React 19 + TypeScript
- **Build Tool**: Vite 7
- **Styling**: Less CSS
- **HTTP Client**: Axios
- **Routing**: React Router v7
- **Linting**: ESLint

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/Ernur-man/adminPage.git

# Navigate to project directory
cd adminPage

# Install dependencies
npm install
```

## 🚀 Usage

```bash
# Development server (with Hot Module Replacement)
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Lint code
npm run lint
```

## 📁 Project Structure

```
src/
├── components/     # React components
├── pages/          # Page components
├── styles/         # Less stylesheets
└── App.tsx        # Main App component
```

## 🔧 Environment Variables

Create `.env.local` file with:
```
VITE_API_BASE_URL=http://your-api-url
```
